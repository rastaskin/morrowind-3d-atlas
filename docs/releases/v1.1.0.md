# Windows installer — 1.1.0

Готовый установщик для Windows 10/11 x64. Python отдельно устанавливать не требуется.

## Запуск

1. Скачайте `Morrowind-3D-Atlas-Setup-1.1.0-win-x64.exe`.
2. Установите приложение для текущего пользователя, откройте его из меню «Пуск».
3. Выберите оригинальную папку `Data Files` своей Morrowind GOTY и нажмите «Подготовить ресурсы».
4. После подготовки нажмите «Открыть карту». Окно управления нужно оставить открытым.

Карта открывается в браузере на `127.0.0.1:8768`. Сохранения OpenMW `.omwsave` формата 34 обрабатываются в браузере. Для переноса прогресса с версии из исходников используйте JSON-экспорт/импорт.

## Что включено

- Локальный мастер первого запуска и Python-runtime с необходимыми библиотеками.
- Установка без прав администратора, ярлык меню «Пуск», необязательный ярлык рабочего стола и деинсталлятор.
- Исходники сборки установщика и дополнительный скриншот мастера в README.

Игровых моделей, текстур, архивов, шрифтов и чужих сохранений в установщике нет. Ресурсы собираются из собственной копии игры. После удаления программы кэш и браузерный прогресс сохраняются.

## Проверки

- Установка, запуск установленного EXE и удаление.
- Встроенные библиотеки, чтение BSA/NIF, PNG и WOFF2.
- Полная подготовка карты из упакованного EXE: 1 130 ячеек, 1 564 модели, без ошибок экспорта.
- HTTP-раздача интерфейса и ресурсов, блокировка обхода каталогов и серверной загрузки сохранений.
- Проверка отсутствия личных путей в файлах сборки и именах Python-кода.

Файл пока не подписан цифровым сертификатом. Для проверки целостности рядом опубликован `SHA256SUMS.txt`.
