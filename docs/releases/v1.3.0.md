# Обновление по кнопке — 1.3.0

В окне программы появилась кнопка «Проверить обновления» и номер установленной версии.

1. Нажмите «Проверить обновления».
2. Если найден новый выпуск, нажмите «Обновить до …» и подтвердите установку.
3. Дождитесь загрузки и перезапуска программы. Открытую страницу карты при необходимости обновите.

Программа получает установщик из GitHub Release этого проекта, проверяет размер и SHA-256, закрывается, устанавливает новую версию и открывается снова. Подготовленные ресурсы и прогресс в прежнем браузере сохраняются. Интернет нужен только при нажатии кнопки; фоновых проверок нет.

Ошибка сети, повреждённый или неполный файл не запускают установку. Предварительные версии и понижение версии не предлагаются. Во время подготовки ресурсов обновление недоступно.

Для 1.2.0 и старше нужно один раз установить этот выпуск поверх прежнего: в старых версиях кнопки ещё нет. В дальнейшем можно обновляться из программы.

Проверены 19 тестов интерфейсной логики, лора и сохранений и 11 Python-тестов обновления, включая PowerShell-синтаксис помощника установки и защиту от повреждённых загрузок. Сборщик игровых ресурсов не менялся.

Установщик Windows x64 и его SHA-256 приложены к релизу. Игровые архивы, ресурсы и пользовательские сохранения не включены. Установщик пока без цифровой подписи.
