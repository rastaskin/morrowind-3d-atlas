# Обновление по кнопке — 1.3.1

В окне программы рядом с номером версии есть кнопка «Проверить обновления». При наличии нового выпуска она становится кнопкой «Обновить до …»: после подтверждения программа скачивает установщик, проверяет SHA-256, устанавливает обновление и перезапускается.

В этом выпуске загрузка идёт через официальный API файлов GitHub Release. Это позволяет получать установщик, когда обычная браузерная ссылка возвращает ошибку 504. Адрес, размер и контрольная сумма по-прежнему проверяются.

Подготовленные ресурсы и прогресс в прежнем браузере сохраняются. Повторная подготовка карты не требуется. Фоновых проверок обновлений нет.

Для версии 1.2.0 и старше один раз установите этот выпуск поверх прежнего. Дальше обновления доступны внутри программы.

Проверены 19 Node-тестов и 14 Python-тестов обновления, включая официальный API загрузки, контрольные суммы, неполные файлы, отмену и помощник установки. Установщик Windows x64 и SHA256SUMS приложены ниже. Игровые файлы и пользовательские сохранения в него не включены.

Проверена установка поверх 1.2.0, автоматический повторный запуск, работа карты на прежнем адресе и кнопка проверки в установленном EXE. Активный кэш и файлы подготовленного мира сохранились без изменений.
